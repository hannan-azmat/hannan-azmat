# 💫 About Me:

Full-Stack Engineer with 6 years of experience owning products from the PostgreSQL schema to the shipped interface. Built **Trackivo** end to end as the only developer on the stack (NestJS APIs, four role-based web portals, Flutterwave payments) and led the twelve-module **SandSeekers** admin platform, closing a production concurrency defect with optimistic locking and real-time events. Builds Next.js and React web applications, ships Flutter and React Native apps to both stores, and works with LLMs, including a retrieval-grounded OpenAI pipeline that rejects any figure the sources don't contain. Integrates payment, messaging and travel APIs, writes API specifications that align clients before build, and authored the clean-coding standards used across company teams.
